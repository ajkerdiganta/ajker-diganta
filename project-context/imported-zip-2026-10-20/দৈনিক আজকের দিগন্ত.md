# দৈনিক আজকের দিগন্ত

A Bengali-first news platform MVP built with Next.js 16 App Router, TypeScript, Tailwind CSS 4, PostgreSQL 16+, Prisma 7, Better Auth, and TipTap. Product phases currently include newsroom CMS, public news/video pages, personalization, notifications, PostgreSQL Bengali search, admin analytics, and security hardening.

## Requirements and local setup

- Node.js 22.12+ (22.18+ recommended), pnpm 11+, PostgreSQL 16+.
- Copy `.env.example` to `.env`; set development, shadow and disposable integration-test database URLs; generate a random `BETTER_AUTH_SECRET` with `openssl rand -base64 48`.
- Provision PostgreSQL roles and databases as described in [DATABASE.md](DATABASE.md). Do not use a production database for local development/tests.

```sh
cp .env.example .env
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:migrate
pnpm db:seed
pnpm dev
```

The UI and editorial content are Bengali-first (`bn-BD`); dates display in `Asia/Dhaka`. Noto Sans Bengali and Noto Serif Bengali variable fonts are self-hosted and subset to Bengali script, with system fallbacks for other scripts. News URLs use stable lowercase ASCII transliterations; searches use PostgreSQL `pg_trgm`/GIN indexes and parameterized queries.

## Main routes

Public: `/`, `/latest`, `/category/[slug]`, `/news/[slug]`, `/author/[slug]`, `/search`, `/video`, `/video/[slug]`, `/about`, `/contact`, `/privacy`, `/terms`, `/sitemap.xml`, `/robots.txt`, `/feed.xml`.

Accounts: `/login`, `/register`, `/forgot-password`, `/reset-password`, `/dashboard`, `/notifications`. CMS roles enter through `/cms-access`; admin newsroom is under `/admin`, including `/admin/analytics`.

See [API.md](API.md), [ADMIN_GUIDE.md](ADMIN_GUIDE.md), and [ARCHITECTURE.md](ARCHITECTURE.md) for the route, role, and system breakdown.

## Runtime configuration and deployment

Never commit `.env` or real credentials. `.env.example` is illustrative only. Configure production PostgreSQL, the independent migration credential, HTTPS origins, email, R2 storage, and an internal job secret as documented in [ENVIRONMENT.md](ENVIRONMENT.md). The app requires a Node.js server runtime; Cloudflare can front the origin and R2 can store media, but direct Cloudflare Workers compatibility is **not yet verified**. See [DEPLOYMENT.md](DEPLOYMENT.md) for staging-first procedure and explicit blockers.

**No deployment or production migration was performed as part of this preparation.** The staging database credentials and external provider settings were unavailable in this environment; the staging migration and environment-specific checks remain a release gate.

## Commands

```sh
pnpm dev                 # local development
pnpm typecheck           # TypeScript
pnpm lint                # ESLint
pnpm test                # unit tests
pnpm test:integration    # isolated PostgreSQL integration tests; requires TEST_DATABASE_URL ending _test
pnpm build               # production build
pnpm db:generate         # Prisma Client
pnpm db:migrate          # local development migration (Prisma migrate dev)
pnpm db:deploy           # apply committed migrations; NODE_ENV=production requires MIGRATION_DATABASE_URL
pnpm db:seed              # local RBAC seed; production requires the migration/operator URL
pnpm admin:promote EMAIL --confirm EMAIL  # controlled verified-account elevation
```
